# SilvaQuieta

SilvaQuieta — настольное приложение для каталога растений, личной коллекции и журнала наблюдений. Доступно для macOS, Windows и Fedora Linux.

## Скачать

[Открыть последнюю версию в GitHub Releases](https://github.com/Site-Developer00/silvaquieta/releases/latest)

В разделе **Assets** выбери файл для своей системы:

- **macOS** — `.dmg`, Apple Silicon и Intel
- **Windows** — `.exe`, x64
- **Fedora Linux** — `.rpm`, x86_64

## Важно

Репозиторий предназначен для распространения готовых сборок. Исходный код приложения здесь не публикуется. Установщики пока не подписаны сертификатами разработчика, поэтому при первом запуске система может показать предупреждение.
